# Remote Play — user manual

Operator and administrator manual for **Remote Play**, a web gateway for Axia
Livewire and AES67 audio-over-IP.

- **[Read the manual](user-manual/remoteplay-manual.html)** — rendered HTML
  (also readable as [markdown](user-manual/README.md)).
- **[manual-maintenance.md](manual-maintenance.md)** — how the manual is kept
  current: staging an instance, capturing screenshots, regenerating the HTML.

This repository is a **mirror**. The source lives in the private
`remoteplaycore` repo under `docs/`, and is synced here by its
`publish-manual` workflow on merge to main — edits made here are overwritten.
